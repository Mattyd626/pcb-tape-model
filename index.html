How to export the DXF from KiCad
  1. In the PCB editor, open File → Plot.
  2. Set the format to DXF and tick only the copper layer you want (e.g. F.Cu).
  3. Leave Plot graphic items using their contours on, units in millimetres, and set the drill marks to Actual size to get holes.
  4. Click Plot and drop the resulting …-F_Cu.dxf here.
